# 🏃 Treinador Mateus Lucas

Aplicativo web para gerenciamento de ciclos de treino de corrida.

## ✨ Funcionalidades

- 📊 Dashboard com visão geral dos atletas
- 🏃 Gestão de ciclos de treino (4-52 semanas)
- 📈 Cálculo automático de zonas de treino
- 🎯 Parser QuickAdd para adição rápida de treinos
- 🔄 Drag-and-drop para reorganizar programação
- 📋 Relatório A4 imprimível
- 💾 Backup/Restore em JSON
- 🌙 Dark mode
- 📱 Responsivo (mobile/tablet/desktop)

## 🚀 Acesso Online

Hospedado na Netlify: [https://seu-site.netlify.app](https://seu-site.netlify.app)

Auto-deploy a cada push no GitHub.

## 💻 Tecnologia

- **Frontend:** React 18 + Babel standalone (CDN)
- **Dados:** localStorage (sem servidor necessário)
- **Estilos:** CSS puro com design system
- **Deploy:** Netlify + GitHub
